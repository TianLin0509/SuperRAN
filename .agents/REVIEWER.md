# 这份合同已改名

**审 PR 并执行合并的角色现在叫「合并 Agent」，合同在 `.agents/MERGER.md`。**

如果你是被一段旧交接词指到这里的，直接去读 `.agents/MERGER.md`，按它工作。

## 为什么要留这个桩

2026-09-04 之前的 `REVIEWER.md` 写的是「**禁止**改 Author 分支、提交、合并、push」，
角色只出结论、不执行合并。实际用下来维护者每次还要自己去点合并，很累。

现在改成：**审完 PASS 就由同一个 Agent 执行合并**，并配三条硬闸
（不许审自己写的、只有 PASS 才合、合的必须是它亲自验过的那个 SHA）。

旧交接词还在外面流传，所以留这个桩，免得有人读到「禁止合并」又停在半路。
