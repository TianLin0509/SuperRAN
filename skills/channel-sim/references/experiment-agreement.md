# 实验约定：从人话到实际运行

**什么时候读**：要生成新数据、执行仿真、续跑旧实验或改变条件时。
这是 Agent 工作约定，**当前没有对应的自动合同执行器或完整恢复状态机**。
利用已有 Draft、预注册、dataset_id、result_id 留痕；Agent 负责核对它们是否一致。

## 人看到的一页约定

按任务取需要的行；数据交付与概念讨论不要填没有意义的比较项目。

| 项目 | 写什么 |
|---|---|
| 要回答的问题 | 一句通信问题；完成后人要做什么判断 |
| 研究机制 | 哪个量改变，通过什么物理/调度环节影响什么；标为待检验假设 |
| 改变什么 | 方案/基线与唯一或明确列出的变化轴；扫描范围 |
| 固定什么 | 场景、载频/带宽、阵列、用户分布/速度/方向、信道获取方式、负载、资源与随机流 |
| 怎么看结果 | 主指标及方向、分子分母/统计对象/窗口；辅助指标用于解释而不取代主指标 |
| 什么结果可信 | 物理体检、公平性、数量级/守恒/退化检查；比较再加预注册与统计判决 |
| 预算与结束条件 | 试点还是正式、可用时间/资源、数据或报告交付物；证据不足如何结束 |
| 边界 | 实际建模内容、近似、不支持的条件、不能推广到哪里 |

首次复述即可发现误解，**不增加通用的“签字后才能跑”门槛**。已有明确执行授权直接
继续；缺失且确实影响结果的决定才问人。用户授权默认不等于授权改写他已给出的条件。

## Agent 保存的记录

在项目 `artifacts/` 或 `output/` 的本实验目录保存 UTF-8 约定与执行记录。
可使用 Markdown 约定 + JSON 参数；不把内部字段名当成人的必答题。

- 原始需求与约定修订号；每个关键条件来源标成用户指定、继承、预设默认或 Agent 建议。
- 原话 → 条件 → 实际参数的映射。分别记录生成参数、每个系统方案参数及预注册口径。
- 数据/结果句柄、源码版本、provenance、实际配置回显、体检和比较判决，以及未执行项。
- 每次改动覆盖对应约定正文，历史另存；不保留互相矛盾的有效条款。

这是可检查的持久记录，不代表运行时已经强制执行了它。不能把未来设计写成当前能力。

## 三次核对

**生成前**：约定里的阵列、带宽、用户数、样本数、场景、剖面、速度、运动方向、时间间隔
逐项进入生成配置。若 `sr_plan` 默认与用户原话不同，用结构化参数修正并重新读取草稿。
系统场景的 `generate` 段与 `system` 段分开保存；任务分类标签不足以证明路由正确。

**每臂运行前**：基线/候选只差声明的因素，实际传给 `sr_system_sim` 的参数有记录。
检查主指标对应话务模型；系统单臂重复不是比较判决。用共同随机数 CRN（Common Random
Numbers）让两方案经历对应的话务/抽签，即控制无关随机变化，而不是挑种子。

**运行后**：以数据摘要、返回配置与有效资源分配为准复核约定；尤其检查自动周期、
栅格处理、实际秩、CSI 口径、实际重复数、未建模项及 `notes`。没有回显的条件写“未核实”，
查本次元数据或实现证据补齐；不得凭传参成功说生效。偏差影响问题时不发布结论。

## 不同问题的判断边界

| 请求 | 应用方式 |
|---|---|
| 20 样本 PDP | 数量是交付要求；不调用收益样本规划，不虚构算法基线 |
| PF 与 EDF 小包时延 | 比例公平与本平台 EDF（Earliest Drain First，最早排空优先）的比较；不是经典 Earliest Deadline First 截止时间调度。选有限到达话务、同负载与随机流，明确完成时延/等待/超时哪一个为主 |
| SRS 周期变化 | 保留速度和方向、相关快照、时间间隔与 CSI 老化；固定/核对有效周期，避免自动资源策略消除变化 |
| 满缓冲边缘体验 | 明确窗口发送速率与忙期吞吐不同，使用适用 KPI；None 不是零 |
| 多载波 CORT | 先查 CA 配置与当前支持的调度策略、每载波栅格；不能把单载波重复两次称为载波聚合 |
| TDL 到达角估计 | 缺逐径角度，说明无法回答；推荐改用空间模型并解释其代价，不能暗换 |
| 旧实验追加测量量 | 同批数据重新 deliver，无需重新随机生成；先确认该量确实已存在/可推导 |
| 旧实验换主指标 | 新问题标探索性或预先设计新数据实验；禁止看完结果再补预注册 |

## 合理性解释

用检查而非故事解释结果：容量/谱效上界、资源是否重复记账、单用户或静止退化、
误块率与重传是否同向变化、队列是否收敛、总吞吐与用户分位是否冲突。
区分预期机理与实际观测；不符合预期时保留异常及待查原因，不能改口径把结果讲圆。
正式预算耗尽而门未过就交付“不足以判断”及工具给出的后续样本建议，不无限循环。
