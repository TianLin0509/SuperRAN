## 改了什么物理机制

| 批次 | 改动与输入输出 |
|---|---|
| 同站同步载波聚合（CA，Carrier Aggregation） | 一个终端只有一份业务到达、队列与用户统计；多个分量载波各自维护信道质量反馈、空间层数、外环链路自适应及混合自动重传状态。支持独立分流与 CORT 二轮调度修正，后者在首轮计划后用空闲资源扩大新传授权。 |
| 多普勒与到达方位（R1） | 同一射线的到达方位角与终端水平运动方向共同决定其频移；位置推进、服务与邻区链路、上行交叉链路和历史测量取用统一的有效运动方向。 |
| 信干噪比与相关性聚合（R4） | 一个资源块组（RBG）内先将各资源块（RB）的信干噪比（SINR）转成 dB，再求算术平均；同一用户的残余相关性损失按各空间流的 dB 损失求和，归属该用户的单一码字。接收 SINR 的跨流 dB 平均口径保持原约定。 |

载波聚合保留已就绪重传优先级，按整字节分流；全局比例公平历史每个传输时刻只更新一次。同一用户、同一时刻在不同载波发送的首传净荷先合并，再统计业务忙期，避免将并行发送时间或用户人口重复计数。

结果保存完整的载波输入身份、数据来源、逐载波覆盖及资源授权。某个载波失覆盖而另一个载波仍可服务时，不将用户记为全局失覆盖；跨频没有明确可加含义的干扰和几何指标保留在各载波诊断中。

## 为什么

单载波调度无法描述同一文件同时使用多个载波。若直接把几个单载波结果相加，会重复产生业务、计算比例公平历史或累计忙期时长。共享队列和统一时钟保证实际发送字节与资源消耗能够对账。

原多普勒计算使用的方向可能与射线空间响应或实际终端运动方向不一致。比如终端向北走、射线沿东西方向到达时，水平速度在来波方向上的投影应接近零；不能再另抽一个方向产生频移。

SINR 在线性域平均后再转 dB，与逐 RB 的 dB 算术平均不同。将两流残余损失平均，也不同于把两流损失共同归入一个码字。本批按已确认的聚合约定修正这些差异，避免链路判决和配对代价采用不同口径。

## 没证明什么

- 未发布 CA、R1 或 R4 的吞吐提升百分比，未证明与对标实现逐阶段等价或与现场设备全面一致。功能反例与字节守恒不替代正式性能实验。
- CA 当前是同站、同步、30 kHz 子载波间隔；内置载波配置为 100 MHz/272 PRB 与 20 MHz/51 PRB。混合子载波参数、异步帧、跨站、非零载波间延迟及自动辅载波激活不支持，相关配置会被拒绝。多载波要求比例公平与逐 RBG 频选，图形配置页面尚未新增 CA 表单。
- R1 仍是水平到达方位和水平速度的二维投影，不含完整三维天顶角与垂直速度；连续相位不等于完整散射体空间一致性。不能宣称任意定向 CDL/视距信道都符合 Jakes 相关曲线。
- 新旧版本即使使用同一种子也不保证逐位相同；旧数据和旧结果只能按原版本追溯，正式比较须核对数据来源及适用性。
- R4 固定的是本项目已确认的 dB 聚合合同，不代表所有误块率模型的通用有效 SINR 算法，也不自动构成经过标定的 EESM/MIESM 链路映射。
- 本次目标为 GitHub `develop`；`main` 是独立发布引用，本次不更新。

## 影响哪些 KPI

| 指标 | 影响与证据边界 |
|---|---|
| 总吞吐、用户忙期吞吐、完成时延 | CA 改变可使用资源及跨载波发送时序，量级需另做受控实验；本批未测量统一增益。 |
| 载波利用率、实际授权与失覆盖计数 | 改为按载波身份记账并正确聚合，避免混用不同带宽的分母或忽略可用辅载波。 |
| 信道时间相关性、CSI 老化及波束失配 | 受实际运动方向与射线到达方向共同影响；不能将二维修正外推为完整移动信道已验证。 |
| 单/多用户选择、MCS、首传误块率、残余误块率 | SINR 和多流相关性聚合会改变判决，方向依场景而定；本批不发布统一升降幅度。 |
| 算法比较结果 | 依赖完整载波来源身份和公共随机数；输入或物理版本改变后须重新验证配对条件。 |
