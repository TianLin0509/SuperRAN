# 历史开工资料

此目录保留 2026-09-25 的开工会方案、八份任务书、交付模板和生成工具，供追溯当时的分工建议。
它不再作为当前启动要求，不要求先开会议、完成勾选或按旧代码包渠道交接。

当前 Agent 开发入口是仓库 [AGENTS.md](../../AGENTS.md)，首次安装见
[INSTALL_AGENT.md](../../INSTALL_AGENT.md)，阿里云候选提交、独立审核与主干发布见
[.agents/SYNC.md](../../.agents/SYNC.md)。原分工内容保留，不代表成员已确认或完成。

页面、复制的任务摘录、任务书和协作说明都带历史提示。`build.py` 从模板与原分工重新生成这些材料，
生成时仍保留提示；重新生成或本地验收不代表重新部署历史网站。

`verify.py` 是历史浏览器验收脚本，包含系统剪贴板和 PDF 写入操作；自动化复核应先检查执行边界，
使用隔离副本、无头浏览器和自己的产物目录，不运行到生产数据上。
