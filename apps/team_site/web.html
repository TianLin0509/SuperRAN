让你的 agent 更新

负责人提供个人接入配置后，将接入说明交给你的 agent。

  1. 开始一项工作时创建记录，保留返回的工作编号。
  2. 有实际进展、遇到阻塞、完成自测或交付时，上报简短进展。
  3. 更换电脑或 agent 时沿用工作编号，继续更新同一条记录。

断网时进展先保存在本机，下次调用时补传。接入说明中的持续重试命令可在 agent 停止后继续补传。

网站不会读取你的会话或代码；只有明确上报的摘要和成果链接会被全组看到。
